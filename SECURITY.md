# Security policy

## Supported versions

Only the latest source snapshot in this repository, and the current installer
release, receive security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the Security tab
of this repository and choose "Report a vulnerability" (private vulnerability
reporting). Do not open a public issue for a security problem.

Include what you found, how to reproduce it, and the snapshot or installer
version you tested. Fixes land in the private source repository first and reach
this repository with the next snapshot.
