# Contributing

This repository is a source snapshot exported about once a month from a private
repository. Pull requests here cannot be merged directly, because the next
snapshot replaces the whole tree.

- Issues are welcome: bug reports, reproduction steps and feature requests.
- If you send a fix as a pull request, it may be reimplemented in the private
  repository and arrive with a later snapshot, with credit in the issue.
- For security problems, follow [SECURITY.md](SECURITY.md) instead of opening an
  issue.
